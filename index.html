Como funciona

01

Service Worker

Intercepta requisições e entrega os arquivos pelo Cache API quando não existe conexão.

02

IndexedDB

Guarda candidatos, votos e eventos localmente para que a aplicação continue funcionando offline.

03

Background Sync

Registra uma tarefa de sincronização quando o usuário vota sem internet.

04

Push

Demonstra permissão e notificações locais, além de registrar eventos relevantes da eleição.
